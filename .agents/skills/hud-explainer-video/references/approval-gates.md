# 动效解说视频六大强制量化门禁（Approval Gates · v6.0）

> **门禁铁律**：覆盖渲染前静帧全检（Step 4）与成片交付终审（Step 5）。**任意一项不达标（FAIL），必须立即在源码层修复并重检，严禁带病启动全量 4K 渲染或带病交付。**

---

## Gate 1 · 节奏密度与时序因果门禁（Pacing & Causality）
- [ ] **零呆板停滞**：非截屏保存段落，画面连续无实质变化（新元素入场、3D 镜头推拉、焦点转移、状态递进）的时间 **≤ `3.0s`**（严禁仅靠虚线流动或圆环自转充当变化）。
- [ ] **截屏窗口充足**：口播明确引导保存的“抄作业提示词卡”与“结尾选型口诀卡”，在文字出齐后保留 **`2.5–4.0s`** 清晰稳定停留窗口。
- [ ] **时序因果严密**：
  - 并列角色/载体/标签严格按口播念到的先后帧逐个点亮强调；
  - **零提前剧透**：验收通过（如 `PASS ✓`）、最终结论等终态元素，严禁在口播讲到对应因果节点前提前挂出；
  - 两段式递进金句严格执行“前半白亮常驻 + 后半压暗待命 → 念到时琥珀金点亮”。
- [ ] **全片水准恒定**：成片中段、后段、结尾的微拍频率与组件精致度与前 40 秒样片完全一致。

## Gate 2 · 手机端零疲劳与版面可读门禁（Mobile Readability）
- [ ] **组件禁长句**：除“截屏保存”专用卡外，所有视觉组件内部主文案控制在 **`2–6` 个字**（严禁照搬口播长句），搭配直观动态微图示或大数字。
- [ ] **同屏做减法**：单一微拍同屏清晰聚焦的主体控制在 **`1–3` 个**；超过 3 个节点的流程已启用镜头推近特写跟随。
- [ ] **字号硬底线**（基于 `1920×1280` 逻辑画布）：
  - 章节/卡片核心大词 **≥ `46px`**；
  - 辅助短标签/副标 **≥ `28px`**；
  - 画面内任何需辨认的文字（含终端代码、模拟消息板、局部截图文字）等效字高 **≥ `24px`**（彻底清零手机端看不清的缩微段落）；
  - 底部全局字幕 **`54–58px`** 细常规白体（`fontWeight: 400`），单行不遮挡主视觉。
- [ ] **细体通透铁律（零粗黑伪加粗）**：全片字重严格控制在 **`300`（Light 细体）/ `400`（Regular 常规）/ 最高 `500`（Medium）**，开启 `fontSynthesis: 'none'` 与 `-webkit-font-smoothing: antialiased`；**严禁使用 `>= 600` 粗黑体或窄黑 `DIN Condensed`**（防止触发 macOS `PingFang SC` 伪粗体描边导致笔画粘连发脏），视觉主次依靠字号反差、留白与色彩光影建立。
- [ ] **Chrome 四色克制铁律**：全片彩色严格限定在 **Chrome 图标四色**（`CHROME_RGB`：**橙 `#F5A623`、蓝 `#4285F4`、红 `#EA4335`、绿 `#34A853`**）+ 暗调中性灰白黑，**严禁引入紫色、洋红、粉红、荧光青等第 5 种彩色**（由 `scripts/lint-gates.mjs` 自动拦截）；**严禁在组件或列表项单侧边缘加竖条（`borderLeft`/`borderRight`）**。
- [ ] **零背景串扰 + 重心平衡**：背景描边水印在中央主体区已做遮罩衰减，不穿透干扰毛玻璃文字；无单侧大面积死黑空洞。

## Gate 3 · 物理阻尼、3D 融合与转场门禁（Physics, 3D & Transitions）
- [ ] **干脆物理手感**：组件入场 `10–14` 帧利落落位（`CRISP_SPRING`），3D 翻卡 `14–16` 帧干脆到位；堆叠落卡严格遵循“底层先落、顶层后落”。
- [ ] **落位绝对静止**：组件落定后**零 `Math.sin` 上下浮动**、零高频抖动（`shake`）。
- [ ] **零闪抖铁律**：全片颜色变化均通过 `mixRgb` 连续插值（**零布尔阈值硬跳色**）；卡片边框恒定 `2px`（零 `borderWidth` 动态跳变）；列表高亮采用行内连续 RGB 填充（零跨行滑条拖影）。
- [ ] **文字去贴纸感 + SVG 安全**：所有毛玻璃卡片均包含覆盖于文字层**上方**（`zIndex: 10`）的动态反光扫光层；SVG `<defs>` 渐变与滤镜 ID 均通过 `useId()` 隔离无重名冲突。
- [ ] **无感转场零叠影**：章节切换优先采用同构几何形变接力（Shape-Match Morph）或差异化 3D 运镜，无前后两场文字半透明交叉叠影，无帧间硬切。

## Gate 4 · 几何多样性与零穿模溢出门禁（Geometry & Zero-Overflow）
- [ ] **零模板化**：全片未使用已淘汰的 `HudFrame` 左右大框模板，无连续两章重复使用同一种圆角长条竖排布局。
- [ ] **零溢出与零孤字**：全量容器启用 `boxSizing: 'border-box'`，实帧核查无文字撑破边框、无遮挡、无标题末尾单字换行（孤字）。
- [ ] **连线边缘精准**：所有流程图/拓扑/阶梯连线均精确起止于节点几何外边缘（零刺入圆盘/卡片内部、零穿字、进度 `<= 0.02` 时零圆头残留点）。

## Gate 5 · 官方视觉证据与声画品质门禁（Official Assets & Audio）
- [ ] **矢量官方标识**：涉及的所有产品、模型、工具与语言均使用 `BrandLogos.tsx` 矢量官方图标，零通用 emoji 敷衍替代。
- [ ] **真 4K 截图零模糊**：所有嵌入的官网深色局部图均经 `sips` 验证 **`原图宽 ≥ 容器逻辑宽 × 2`** 且 `objectFit: 'contain'` 零裁字；原始像素不足的小尺寸 UI 已改为 1:1 矢量组件精绘。
- [ ] **口播原样使用 + 4 类固定 `-16 dB` 微音效**：直接使用用户提供的原始口播音频（保持原音量、语速、停顿与时序，**严禁做响度标准化篡改**）；微音效严格收敛为 `enter` / `focus` / `flip` / `transition` **4 类**，全部统一固定 **`-16 dB`**（不做自适应音量），通过 `<Sfx>` / `<SfxGroup>` 同源绑定、无爆音。

## Gate 6 · 编译、V3.1 回归、动态复核与闭环复盘门禁（Build, Regression & Retro）
- [ ] **静态编译与自动门禁通过**：`npm run check`（`tsc --noEmit` + `scripts/lint-gates.mjs` + SRT 锚点单测）零报错。
- [ ] **四大标杆维度逐章动态验收 PASS**（以已确认的 V3.1 样片 `v3.1-approved-sample` 为最终视觉依据）：
  - **画面层级**：缩到手机宽度第一眼能否找到当前主角？标题/主体/辅助/字幕是否各守其位？
  - **组件**：新组件的大字、玻璃厚度、边缘受光、投影与间距能否与 V3.1 主牌放在同一幕而不违和？
  - **动效**：中后段各章已用预览渲染 + `npm run motion-strip` 连拍条核验起动、落稳、重音卡点与跨章衔接（严禁仅凭单张静帧放行）？
  - **演绎方式**：每句关键口播是否都有“观众一眼看懂因果关系”的清晰视觉动作？
- [ ] **共享组件变更 V3.1 回归 PASS**：若本轮改动过 `src/engine/` 共享组件，已运行 `npm run regression:v31` 并目视确认并排对照图无视觉退化。
- [ ] **成片自动 QC（`npm run qc`）与衔接终审 PASS**：以 `<成片>.qc/qc-report.md` 为唯一技术放行依据——分辨率精确为 `3840×2560`（或指定预览尺寸）、`30/1` fps、`yuv420p`、`h264 + aac` 双轨、真峰值 `≤ -0.5 dBFS`（综合响度按原声记录为 INFO 不做强制篡改）、平均码率 `≤ 20 Mbps`、零异常冻帧/黑帧，且最终成片的章节衔接已连续复看无瑕疵。
- [ ] **强制复盘落盘**：交付后已将本期得分诊断与下期 2–3 个可验证实验项写入 [retrospective-log.md](./retrospective-log.md)。
